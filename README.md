# Coleta NFS-e Nacional — atualizações

Este repositório publica os instaladores Windows x64 e os manifestos de atualização assinados do Coleta NFS-e Nacional.

Os pacotes são releases completas. O aplicativo verifica a assinatura RSA-PSS/SHA-256 e o hash SHA-256 do instalador antes de oferecer uma atualização.

Consulte a release mais recente para baixar o instalador. Este repositório não contém banco de dados, cadastros, documentos fiscais, certificados ou credenciais.
